# Ciallo

一个有趣的网页动画项目，展示带有随机颜色和动画效果的 "Ciallo～(∠・ω - )⌒★" 文本。

## 功能特性

- 随机生成带有不同颜色和大小的 "Ciallo～(∠・ω - )⌒★" 文本元素
- 文本元素从屏幕左侧滑动到右侧
- 点击文本元素会触发动画效果（放大、变色、消失）
- 自动控制屏幕上同时存在的文本数量（桌面端最多75个，移动端最多25个）
- 支持键盘交互：每个文本元素携带一个随机字母，按下对应的键盘字母可以触发效果
- 统计功能：显示总按键数、正确/错误按键数和准确率
- 可自定义最大文本数量（1-200），设置会保存在本地存储中
- 版本信息显示

## 安装和使用

1. 克隆或下载此项目到您的本地计算机
2. 确保您已经安装了Web服务器（如Apache、Nginx）或者使用简单的HTTP服务器，例如Python的`http.server`或Node.js的`http-server`
3. 将项目文件放在Web服务器的根目录下
4. 在浏览器中打开 `http://localhost/index.html` 访问页面

或者，您也可以直接在浏览器中打开 `index.html` 文件，但某些功能可能需要通过HTTP服务器访问才能正常工作。

## 自定义设置

- 通过URL参数 `?max=数字` 来自定义最大文本数量，例如：`index.html?max=50`
- 也可以在页面上使用右上角的控制面板来调整最大文本数量
- 设置会自动保存在浏览器的本地存储中
